# ryukyu-yayoi

Mac 用の仕訳確認アプリ「ryukyu-yayoi」の配布物を置く場所です。ソースは置いていません。

macOS 14 以降。Apple シリコンと Intel の Mac で動きます。

## 入れ方（最初の1回だけ）

1. 開いている ryukyu-yayoi があれば、⌘Q で閉じます。
2. [最新のリリース](https://github.com/mtenma/ryukyu-yayoi-releases/releases/latest) から `ryukyu-yayoi-mac.zip` をダウンロードします。
3. ZIP を開き、`ryukyu-yayoi.app` を「アプリケーション」フォルダへ移します。前の版があれば［置き換える］を押します。
4. 開きます。「開けません」と止められたら、［システム設定］→［プライバシーとセキュリティ］→ 下のほうの［このまま開く］を押します（Apple の開発者の署名をしていないためです）。

ダウンロードフォルダの中から開くと、新しい版に入れ替えられません。必ず「アプリケーション」へ移してから開きます。

## 新しい版

2回目からは、新しい版が出ると、アプリを開いたときに「アップデートのお知らせ」が出ます。［今すぐ更新］を押すと、入力した直しを保存してからアプリを閉じ、新しい版に入れ替えて開き直します。

## 中身

アプリには、仕訳確認のプログラムと Python が入っています。会計データ・写真は入っていません。
Python の利用条件は、アプリの中の `Contents/Resources/python-licenses/` にあります。
